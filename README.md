# SKB-Dev

> SKB Dev Ecosystem — Command Center CLI

Unified command hub for all SKB projects.
Reads `.skb/` metadata from each project.

## Install

    cp skb ~/bin/skb
    chmod +x ~/bin/skb

## Usage

    skb                dashboard
    skb projects       all projects (table)
    skb status         current project details
    skb open <name>    project summary
    skb all            detailed view of all
    skb log <name>     recent commits
    skb todo <name>    open TODOs
    skb issues <name>  open known issues
    skb cd <name>      print cd command
